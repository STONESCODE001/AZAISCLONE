## 🛠 Tech Stack & Architecture
- **Framework**: Next.js 16 (App Router)
- **Styling & UI**: Tailwind CSS v4, custom Design System tokens, Framer Motion, and Lucide React
- **State Management**: Zustand
- **Typography**: Inter / Geist

## 🎨 Design System (Sheybi)
Sheybi is built with a confident, playful, yet adult visual tone targeting Gen Z. It features a modern, clean, and soft interface with carefully curated color tokens, avoiding the serious aesthetic of traditional banking applications.
